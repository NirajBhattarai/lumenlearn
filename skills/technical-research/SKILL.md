# Technical Research

## Required sequence

1. Search the internet
2. Prefer official documentation
3. Check specifications
4. Check source code
5. Check academic papers where appropriate
6. Verify behavior
7. Record references in `docs/research/`
8. Only then implement the explanation

## Never

Invent PostgreSQL/EVM/Redis/OS internals from memory when uncertain.

## Research log format

Question · Sources · Findings · Decision · Reason · Date
