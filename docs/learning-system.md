# Learning System

## Learning loop

```
Intuition → Visual → Animation → Interaction → Code → Experiment
→ Complexity → Internals → Production → Advanced → Exercises
```

## Levels

Beginner → Fundamentals → Intermediate → Advanced → Internals → Production → Research

## Lesson sections (canonical aspiration)

Overview · Mental model · Interactive visualization · Animation · Example · Code · Step execution · Complexity · Internals · Experiment · Common mistakes · Production usage · Exercises · Quiz · References · Further exploration

## Modes

- **Why?** — visual reasoning for claims (e.g. why O(1))
- **Compare** — same workload side-by-side (LRU vs LFU vs ARC…)
- **Experiment** — knobs + metrics (hit rate, evictions)

## Content rule

New lessons are **data** under `src/content/` (+ diagrams). Never trap multi-step narratives only inside page components.

## First vertical slice target

10 polished DS lessons (Array → LFU), with LRU as flagship multi-level demo.
