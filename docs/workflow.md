# Agent Workflow

Every agent MUST follow:

```
Understand → Inspect → Research → Plan → Implement → Run → Test → Visual QA → Review → Improve
```

Never: Prompt → Immediately code → Done.

## Visual QA checklist

Desktop · Tablet · Mobile · Dark · Light · Animation · Typography · Spacing · Responsiveness · Accessibility

Use browser tools/screenshots when available. Compiling TypeScript is not done.
